## Method notes

- Significance uses a **paired** per-row squared-error difference d_i = (sharp−out)² − (blend−out)²; mean > 0 ⇒ blend better. z = mean/SE, 95% CI = mean ± 1.96·SE.
- A sector is `model_subtracts` only if z ≤ −1.64; `calibration_bias` only if the signed bucket error is ≥ 4pp **and consistent in direction** (guards against the soccer-style unweighted-mean artifact).
- CLV is reported for context but never tags a sector model-actionable — a fine-Brier / negative-CLV sector is a timing/selection issue.

## What would change the verdict

A future run flags a sector when its blend is *significantly* worse than the entry line, or shows a *consistent* calibration bias, on *current* data. The fix at that point is model-side (reweight via the sector's walk-forward sweep, or add/refresh the sector's isotonic calibration), validated on an independent walk-forward holdout, and reviewed in a PR — never a gating change.
